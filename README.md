## A. Definition–Use шинжилгээ

Definition (Def) нь хувьсагчид утга оноох, Use нь тухайн хувьсагчийн утгыг ашиглах үйлдэл юм.

- **C-use:** Тооцоолол, утга оноолт, буцаалтын илэрхийлэлд ашиглах.
- **P-use:** Нөхцөл шалгах илэрхийлэлд ашиглах.

### gcd() функц
